# Content Verification Register — Statistics & High-Risk Claims

**Retrieved date:** 2026-09-07 | **Reviewer:** unassigned | **Last reviewed:** 2026-09-07

## Methodology note (read before using any fact below)

All legacy-site content in this audit was extracted using an AI-mediated web-fetch tool that converts HTML to markdown and lightly summarises rather than returning a guaranteed byte-exact transcript. Every crawling agent flagged this independently. Two specific artefacts were observed: a probable first/third-person slip ("for my thesis" vs likely "his thesis") and inability to resolve JavaScript-obfuscated email addresses or JS-rendered video widgets. **Any fact below marked "AI-extracted, not independently re-verified" should be re-confirmed via direct browser/HTML-source inspection before it is used in any public-facing or compliance-sensitive context.** Where independent WebSearch/WebFetch corroboration was obtained from a third-party site (Spire Healthcare, BUPA Finder, Doctify, Circle Health Group), that is noted — but note these third-party directory listings are themselves very likely populated from the same practice-supplied biography rather than being fully independent primary sources, so they corroborate consistency, not ground truth.

**Authoritative source priority applied (per task brief):** 1. GMC register 2. NHS Trust sources 3. Hospital consultant profile 4. University/academic institution 5. Recognised professional body 6. Peer-reviewed publication 7. Client-approved practice info 8. keyholesurgeon.co.uk itself 9. Reputable secondary source.
